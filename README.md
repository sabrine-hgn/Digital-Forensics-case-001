# Digital-Forensics-case-001
A beginner-friendly digital forensics investigation project using simulated evidence and log analysis.


## Project Overview

This project simulates a digital forensics investigation to understand a cybersecurity incident by examining digital evidence and analyzing system logs.

## Project Objectives

- Understand the basics of Digital Forensics.
- Learn how to identify and analyze digital evidence.
- Analyze simulated system logs.
- Build an incident timeline.
- Write an investigation report.
